# AUTOMULA

**Supporting product name:** FormPilot AI  
**Tagline:** Understand forms. Prepare answers. Fill with confidence.

AUTOMULA is an AI-powered browser form assistant. Its Chrome extension detects supported online form fields, retrieves user-approved information from a private knowledge base, generates evidence-grounded answer suggestions, and fills fields only after user approval.

## Product principles

- Human approval before filling; no automatic form submission.
- Evidence-grounded answers; never invent personal facts.
- User-controlled browser permissions and data retention.
- Generic form support with specialized website adapters.
- Strict isolation of each user's profile, documents, and application history.

## Initial MVP

1. User profile and knowledge base.
2. CV/document upload and extraction.
3. Chrome Manifest V3 extension with a side panel.
4. Generic HTML form detection and filling.
5. Google Forms adapter.
6. AI suggestions with source attribution and review.
7. Field verification and application history.

## Repository status

This repository is being initialized in phases. The first implementation branch is `phase-1-foundation`. See `docs/ROADMAP.md` and `docs/ARCHITECTURE.md` for the engineering plan.

## Safety boundary

AUTOMULA does not submit forms automatically, bypass CAPTCHA or MFA, collect passwords or payment details, or execute code generated by an AI model. Users review and approve answers before the extension fills a page.
